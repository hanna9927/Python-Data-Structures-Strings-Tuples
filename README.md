# Python-Data-Structures-Strings-Tuples
# Python Assignment 1 – Data Structures

## 📌 Project Overview

This assignment demonstrates basic Python data structures, focusing on **Strings and Tuples**.

The assignment covers string concatenation, slicing, indexing, string methods, tuple creation, concatenation, repetition, and accessing tuple elements.

## 🛠️ Topics Covered

### Strings

* String Concatenation
* String Slicing
* String Indexing
* String Reversal
* String Methods

  * `upper()`
  * `lower()`
  * `capitalize()`
  * `count()`
  * `replace()`

### Tuples

* Tuple Creation
* Tuple Concatenation
* Tuple Repetition
* Tuple Indexing
* Tuple Slicing
